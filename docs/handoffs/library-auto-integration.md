# Automatic library meeting integration

Owner: current library-meeting chat, checkout `library-meeting/`, branch `codex/library-auto-meeting-20261024`, based on current main `6f890ad`. Implements the user's request for an Arwyn-facilitated meeting that advances without a click for every resident decision, retaining the existing free AI route and limits.

Start is explicit, saves the current town before arming and binds a nonpersisted runner to the exact town object, world ID, meeting ID and epoch. Start cancellation has its own serial, including Pause, hidden tab and pagehide while the save awaits. It resumes town time at normal speed for accepted residents' travel. While running, this meeting takes the existing action lane; automatic manuscript dispatch and ambient AI job generation wait. Ordinary local simulation and player controls remain available. A visible Stop control remains reachable outside the meeting panel.

Actual transport starts share one31second pacing timestamp across meeting/manual/manuscript/player requests. Waiting does not mark requests or spend meeting decisions. The existing global transport lock and strict parse/core commit paths remain. A run token is released only after both logical completion and underlying transport settlement; cancellation cannot reopen the lane or apply a late response. Save failure, hidden tab, import/replay/newtown, local dialogue, explicit Pause/Stop, timeout, invalid result, unavailable AI or exhausted limits stop automatic dispatch until an explicit Start. Reload never arms a run. Player floor and accepted travel wait without calls; an idle all-listening meeting stops without manufacturing a speaker.

Arwyn defaults in the new proposal selector, while Northern remains supported. Saved meetings keep their facilitator. Existing sixteen-decision/six-speech caps, authentication, server shared/player/provider budgets, zero monetary controls, one global request and backgroundConcurrent0 remain unchanged. No schema, migration, provider/secret configuration, paid fallback or raw response logging was added. Complete JSON guidance and validators remain intact.
